Hallym RISC-V 1.0.0, the RISC-V simulator for Hallym University's computer architecture labs — its first release. Write RISC-V assembly, assemble it, run it one line at a time, and watch the registers, memory and every instruction's 32 bits. The assembler and simulator are RARS 1.6, unmodified; the window is the Hallym MIPS Simulator's.

## Download (Windows 64-bit)

One file: **`HallymRISCV-1.0.0-win-x64-setup.exe`**. Run it: it installs for you only (no administrator rights) and adds *Hallym RISC-V* to the Start menu. You do not need to install Java: the program brings its own. Hallym MIPS, if you have it, is left as it is: the two do not touch each other.

The program is not code-signed, so **Windows shows a blue "Windows protected your PC" window the first time. Click *More info*, then *Run anyway*** (Korean Windows: *추가 정보* → *실행*). Step by step: [한국어](https://github.com/ars2323/hallym-riscv-simulator/blob/main/docs/usage/usage.ko.md#windows-경고-창-넘기기).

## What you will see

- **A first screen the program draws.** A circuit board grows out from the middle of the window for about eight seconds — the traces nearest the centre first, the corners last — and then only a few pulses of light keep moving. The card in the middle is the chip: the university's symbol, *Hallym RISC-V Simulator*, and two ways in, *바로 시작* and *튜토리얼 보기*. There is no photograph or video of the campus in the program any more. With Windows' animation effects off, the finished board is shown at once and nothing moves.
- **The same window as Hallym MIPS**: the 21-step tutorial, the Editor, Registers, Text, Data, Inspector and Console, the same keys (Ctrl+S, F10, F5, Esc).
- **Nothing left behind on a shared PC.** The program saves only your font size and number base, in its own folder; RARS's own settings are kept in a folder that is deleted when the program closes, never in the Windows registry. The next student starts from the same defaults.
- **RISC-V registers with both their names**: `x10 a0`, grouped as the calling convention groups them; the floating-point registers in their 64 bits.
- **The Inspector in all six formats** (R, I, S, B, U, J): under each instruction's fields, the immediate's scattered pieces put back together into one number — including B and J's lowest bit, which is always 0 and not in the instruction, and the sign extension.
- **RARS's own error messages**, and a guess when a line looks like a typo or a MIPS habit: *`srll` 명령은 없습니다. 혹시 `srl`?*, `$t0` → `t0`, `syscall` → `ecall`.
- Programs start at `main`'s first line (RISC-V has no start-up code here).

## Not checked in this release

- **No black console window when the program starts its engine.** The program starts it in the way that hides that window, and tests pin it, but the Windows test machine never shows such a window either way, so we could not show the hiding at work. If you see a black window flash when the program starts, please tell us.

## Going back

This is the first release of Hallym RISC-V; there is nothing earlier to go back to. To remove it: Settings → Apps → Installed apps → *Hallym RISC-V 1.0.0* → Uninstall. For MIPS, [Hallym MIPS](https://github.com/ars2323/hallym-mips-simulator/releases/latest) stays where it is.
